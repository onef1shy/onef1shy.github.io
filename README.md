# Zeyu Yan / Homepage

个人主页：[onef1shy.top](https://onef1shy.top/)

静态主页由 GitHub Pages 托管，访客地图后端使用 Cloudflare。

- `assets/`、`images/`、`fonts/`：页面脚本、图片和本地字体。
- `analytics/`：地图后端和测试；`scripts/`：地图底图生成工具。
- `CNAME`：自定义域名；密钥、依赖和缓存已由 `.gitignore` 排除。

本地预览可使用 Live Server；维护检查运行 `npm ci`、`npm test`。
后端维护见 [analytics/README.md](analytics/README.md)。
